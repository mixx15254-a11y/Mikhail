# ДФК «Победа» — сайт детского футбольного клуба (Самара)

Одностраничный сайт футбольной школы для детей от 4 лет, сделанный по материалам
сообщества клуба [vk.com/fk.pobeda63](https://vk.com/fk.pobeda63) и текущего лендинга dspobeda.ru.

## Что на сайте

- **Герой-блок** с набором сезона и CTA «Первая неделя — бесплатно»
- **О школе** и принципы подхода («развиваем игроков, а не натаскиваем команду»)
- **Тренеры** — Пильщиков А. В., Кузьмин А. А., Аксёнов А. В.
- **Расписание** сезона сентябрь–май с фильтром по площадкам
- **Абонементы** (4 занятия — 2 500 ₽, 12 занятий — от 4 500 ₽, форма — 3 500 ₽)
- **5 площадок** со ссылками на Яндекс.Карты
- **События, отзывы родителей, FAQ**
- **Форма записи** (работает без бэкенда: собирает заявку и предлагает отправить письмом на dshpobeda@mail.ru или написать в VK) + страница политики конфиденциальности

## Запуск

Сайт статический, сборка не нужна:

```bash
python3 -m http.server 8080   # и открыть http://localhost:8080
```

или просто открыть `index.html` в браузере.

## Структура

```
index.html            главная страница
privacy.html          политика конфиденциальности
robots.txt
assets/css/styles.css стили (без фреймворков)
assets/js/main.js     меню, фильтр расписания, анимации, форма
assets/img/crest.svg  эмблема клуба (SVG)
assets/img/favicon.svg
assets/img/hero-kids.png, drills.png — иллюстрации-заглушки
```

## Как обновлять данные

- **Расписание и цены** — секции `#schedule` и `#prices` в `index.html`
  (данные сняты с dspobeda.ru 18.09.2026 — сверьте актуальность перед публикацией).
- **Контакты** — телефон, почта и ссылки на VK/Telegram продублированы в шапке,
  подвале, секции записи и в `main.js` (mailto формы). Ищите `+7 927 606-88-80` / `dshpobeda@mail.ru`.
- **Фотографии** — `hero-kids.png` и `drills.png` — нейтральные иллюстрации-заглушки.
  Замените их реальными фото тренировок из альбома сообщества VK, сохранив имена файлов.
- **Эмблема** — при наличии официального логотипа замените `assets/img/crest.svg` и `favicon.svg`.

## Перед публикацией

- Укажите реальный домен: `og:image` в `index.html` сейчас относительный —
  для соцсетей нужен абсолютный URL (замените на `https://ВАШ-ДОМЕН/assets/img/hero-kids.png`).
- Проверьте актуальность расписания и цен (сняты с dspobeda.ru 18.09.2026).

## Формат данных формы

Форма не хранит данные: по кнопке «Отправить заявку» она проверяет поля и
собирает готовое письмо (mailto) на dshpobeda@mail.ru либо предлагает отправить
заявку в личные сообщения сообщества VK. Когда появится хостинг с PHP/почтой,
достаточно заменить обработчик в `main.js` на `fetch()` к вашему эндпоинту.
