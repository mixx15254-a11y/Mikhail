# 02 · Фундамент дизайна (вечные принципы)

> Тренды меняются — принципы нет. Источники: Figma Resource Library, Zeka Design, imagine.art, Coursera CalArts, материалы о сетках и композиции.

## 1. Тринадцать принципов (рабочий набор)

1. **Выравнивание (Alignment)** — каждый элемент привязан к сетке или к другому элементу; никакого «примерного» расположения.
2. **Контраст (Contrast)** — принцип различия: размер, цвет, форма, пространство. Нет контраста — всё сливается.
3. **Баланс (Balance)** — распределение визуального веса; симметрия = формальность, асимметрия = динамика.
4. **Иерархия (Hierarchy)** — порядок чтения: сначала главное. Инструменты: размер, цвет, типографика, позиция, пространство.
5. **Цвет (Color)** — и эмоция, и структура; контраст по светлоте важнее контраста по тону.
6. **Белое пространство (White space)** — не пустота, а инструмент: выделяет, группирует, даёт «дыхание».
7. **Пропорция (Proportion)** — соотношения размеров передают важность.
8. **Повторение (Repetition)** — повторяй цвета, формы, стили → целостность.
9. **Ритм (Rhythm)** — закономерные повторы создают поток.
10. **Движение (Movement)** — направляй взгляд линиями, диагоналями, последовательностью.
11. **Акцент (Emphasis)** — одна точка фокуса на композицию; два акцента = ноль акцентов.
12. **Близость (Proximity)** — связанное рядом, несвязанное отдельно (гештальт).
13. **Единство (Unity)** — все элементы ощущаются как одна система.

## 2. Гештальт-законы восприятия

- Близость, подобие, непрерывность, замыкание, фигура-фон, общая область.
- Практика: карточки = общая область + тень/граница; группы формы — отступом, а не линией.

## 3. Композиция и сетки

- **Правило третей** — ключевые элементы на пересечениях линий 3×3; надёжный дефолт, прежде чем ломать.
- **Сетки**: 12 колонок для веба; колонки, желоба (≈20–24px), поля. Модульные сетки для сложных макетов.
- **Золотое сечение / Фибоначчи** — для «органичных» пропорций.
- **30–50% негативного пространства** — ориентир для чистых макетов.
- Начинай макет с сетки; ломай её осознанно и с причиной.

## 4. Визуальная иерархия — правила числами

- Разница между соседними уровнями иерархии ≥ **1.5×** по размеру.
- Один экран/макет = одна главная точка входа (один «король»).
- Порядок: масштаб → цвет → типографика → позиция → пространство; комбинируй, а не полагайся на один приём.

## 5. Цветовая теория (практика)

- **Гармонии**: аналоговая (спокойствие), комплементарная (энергия, для акцентов), триадная (игривость).
- **Правило 60-30-10**: 60% базовый, 30% вторичный, 10% акцент.
- **Психология**: красный — энергия/срочность, синий — доверие/инновации, зелёный — рост, тёмные палитры + металл — люкс/технологии.
- Контраст по светлоте решает читаемость: проверяй обесцвеченной версией макета.
- Строй палитру от бренд-цвета: светлые/тёмные ступени, для каждой — проверенная пара контраста.

## 6. Типографика — базовые нормы

- Кегль тела: **16px+** (веб), межстрочный **≥ 1.4–1.5×**.
- Шкала заголовков: модульная (например ×1.25 или ×1.333).
- Трекинг: крупным заголовкам плотнее, мелкому тексту просторнее.
- Пары: контраст ролей — дисплейный сериф + нейтральный гротеск; не больше 2 семейств (в 2026 допустим один переменный шрифт во многих начертаниях).
- Не набирать большие объёмы курсивом/капсом/узкими начертаниями.

## 7. Отступы и размеры

- Система **4/8pt** — все отступы кратны 4 или 8.
- Внутренний отступ карточки ≥ расстояния между несвязанными блоками; расстояние между группами > расстояния внутри группы.
- Тач-цели ≥ 44×44px.

## 8. Быстрый фреймворк композиции (для постеров/хиро)

1. Одна идея → один фокус.
2. Сетка/трети → позиция фокуса.
3. Контрастный фон → объект читается мгновенно.
4. Заголовок крупно, поддержка мелко, воздух вокруг.
5. Правило нечётности для групп элементов (3, 5).
