# 03 · Доступность (a11y) — WCAG 2.2 и дизайн

> Репозиторий `a11y`, поэтому доступность здесь — не «приятный бонус», а стандарт качества. Источники: руководства по WCAG 2.2, WebAIM-статистика, European Accessibility Act.

## 1. Контраст — обязательные числа

| Тип контента | Уровень AA (минимум) | Уровень AAA |
|---|---|---|
| Обычный текст (<18pt / <24px, bold <14pt) | **4.5:1** | 7:1 |
| Крупный текст (≥18pt≈24px или ≥14pt≈19px bold) | **3:1** | 4.5:1 |
| UI-компоненты и графика (кнопки, поля, фокус-кольца, инфо-иконки) | **3:1** | — |
| Декор, логотипы | без требований | — |

Справка по серому на белом (частые провалы):
- `#767676` на `#FFFFFF` = 4.54:1 — граница прохода AA;
- `#808080` на белом = 3.95:1 — **провал**; комфорт для чтения — `#595959` и темнее;
- чёрный на белом = 21:1 (максимум).

## 2. Типовые ошибки цвета

- Светло-серый текст на белом («выглядит элегантно» ≠ проходит).
- Передача смысла только цветом (статусы, ошибки, ссылки) → добавлять иконку/подчёркивание/текст.
- Текст на фото/градиенте без подложки или оверлея.
- Контраст забывают у состояний: hover, focus, disabled.
- Опасные пары для дальтоников: красный/зелёный, синий/фиолетовый.

## 3. Типографика и разметка

- Тело текста ≥ **16px**, межстрочный **1.5×**, левое выравнивание для длинных текстов.
- Чёткая иерархия заголовков, логичный порядок (не только визуально, но и в коде).
- Избегать сжатых и декоративных гарнитур для чтения.

## 4. Интерактивность

- Видимый фокус-индикатор с контрастом ≥3:1; полноценная работа с клавиатуры.
- Тач-цели ≥ 44×44, достаточные отступы.
- Уважать `prefers-reduced-motion`; анимация объясняет, а не развлекает.

## 5. Юридический контекст (2026)

- **European Accessibility Act** действует с 28.06.2025: требования EN 301 549 ≈ WCAG 2.1 AA. Это уже не «рекомендация», а обязанность для бизнеса в ЕС.
- Статистика сурова: ~94.8% домашних страниц всё ещё имеют обнаруживаемые нарушения WCAG — значит, аккуратный a11y = конкурентное преимущество.

## 6. Чек-лист доступности дизайна (использовать в каждой задаче)

- [ ] Текст проходит контраст 4.5:1 (крупный — 3:1), проверено чекером.
- [ ] Смысл не кодируется одним только цветом.
- [ ] Иерархия читается в ч/б-версии макета.
- [ ] Тело ≥16px, межстрочный ≥1.5, левое выравнивание.
- [ ] Состояния элементов (фокус/ховер/ошибки) различимы без цвета.
- [ ] Тач-цели ≥44px, фокус-кольцо видимо.
- [ ] Нет «тёмных паттернов» (обманных трюков интерфейса).
- [ ] Тёмная тема — не «инверсия», а отдельная палитра с тем же контрастом.

## 7. Инструменты

- WebAIM Contrast Checker — проверка пар цветов.
- Симуляторы дальтонизма (встроенные в Chrome DevTools / Figma-плагины).
- Автоматические сканеры (axe-подобные) + обязательная ручная проверка клавиатурой.
