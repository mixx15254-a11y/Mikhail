# 04 · Промпт-инжиниринг для генерации изображений

> Скил «писателя промптов». Источники: OpenAI Cookbook (GPT Image prompting guide), LetsEnhance 2026, LTX Studio, Cliprise, ImprovePrompt, TransMedia, DubSmart.

## 1. Ментальная модель

Диффузионная модель — не иллюстратор, а рендер-движок. Пиши промпт как **бриф режиссёра съёмки**: кастинг-директор (кто в кадре) + оператор (как снято) + художник по свету (как освещено) + техконтроль (чего быть не должно). Задача — убрать угадывание.

## 2. Мастер-формула (архитектура промпта)

```
СУБЪЕКТ → СРЕДА → КОМПОЗИЦИЯ → СВЕТ → СТИЛЬ → КАМЕРА → КАЧЕСТВО → НЕГАТИВЫ
```

Шестичастная формула (рабочий стандарт):
1. **Субъект** — одно ясное существительное; конкретика: возраст, роль, одежда, поза, эмоция.
2. **Стиль** — медиум, эпоха, художественный референс («арт-нуво иллюстрация», «баухаус-постер», «плёночное фото»).
3. **Композиция** — план и кадрирование (крупный/средний/общий, «вид сверху», «объект слева, воздух справа»).
4. **Свет** — направление, качество, время суток («мягкий контровой из окна слева», «золотой час»).
5. **Палитра** — 2–3 доминирующих цвета.
6. **Техника** — резкость, разрешение, объектив («85mm, малая ГРИП»).

Универсальный шаблон-однострочник:
`Субъект, медиум, стиль, свет, кадр, настроение, палитра.`
Пример: `Портрет бариста, плёночное фото, мягкий контровой свет, 50mm крупный план, тёплое настроение, teal-orange палитра.`

## 3. Правила качества

- **Плотность важнее длины**: 15–50 слов, где каждое слово работает; 20 точных слов бьют 100 расплывчатых.
- Конкретные существительные вместо абстракций (не «радость», а «ребёнок с воздушным шаром»).
- **Одна итерация = одно изменение** (свет ИЛИ ракурс ИЛИ фон).
- Аспект-рейтинг задавай до генерации.
- Негативы обязательны: `без водяных знаков, без лишних пальцев, без текста, без размытия, без артефактов, без хлама на фоне`.
- Противоречия убивают результат («фотореалистичный мультфильм» — нет).
- Не больше 6–7 ключевых деталей; 50 деталей = компромисс по всем.
- Важные якоря — в первые 15 слов (ранние токены весят больше).
- Позитивные формулировки стабильнее длинных списков запретов.
- Для фотореализма — слово «фотореалистичный» напрямую.
- Разделяй в промпте три роли: описание сцены / контроль композиции и материалов / готовность к постобработке (чистый фон, негативное пространство под текст, единый ракурс продуктов).

## 4. Настройки по моделям

| Модель | Стиль промпта | Особенности |
|---|---|---|
| Midjourney V7 | короткие фразы с высокой информационной плотностью | референс-изображения, кинематографические термины («movie still», «depth of field») |
| Stable Diffusion 3.5 | структурированные ключевые слова | веса `(термин:1.2)`, `[термин]` — ослабить; негатив-промпты; ControlNet для поз/композиции |
| ChatGPT / GPT-image | абзацы естественного языка + итерации диалогом | лучший рендер текста в картинках; «сделай диван тёмно-синим», «отъехать на 20%»; указывай размещение («лого справа сверху») |
| Flux | длинные описательные промпты (~500 токенов) | технические детали камеры для фотореализма |
| Ideogram | точные короткие промпты | лучший для типографики в изображениях |
| Seedream | короткие и точные | длинные «украшенные» промпты вредят |
| Nano Banana | короткие свободные промпты | модель для концептинга: 20 направлений быстро, потом победителя в точную модель |

**Шкала CFG**: 1–4 свободное творчество · 5–8 баланс (дефолт) · 9–12 строгое следование (продуктовые кадры, бренд) · 13+ артефакты.
**Сиды**: фиксируй сид для стабильности композиции при переборе промптов и для серий в одном стиле.

## 5. Шаблоны по задачам

**Портрет:**
`[субъект с чертами], [эмоция], [поза], [фон с глубиной], [свет: ключевой/заполняющий/контровой], [камера], [объектив и ГРИП], [плёнка/обработка], [настроение], [палитра]`

**Продукт:**
`[продукт], [материал поверхности], [световая схема], [фон], [ракурс "герой"], [негативное пространство под текст], негативы: без отражений-артефактов, без пыли`

**Логотип/брендинг:**
`минимализм, чистые линии, негативное пространство, векторная эстетика, плоский цвет, одна идея, без градиентов (если не нужно)`

**Хиро лендинга:**
`[идея], широкая композиция 16:9, [палитра бренда], воздух слева/справа под заголовок, [стиль], свет [такой-то]`

**Иллюстрация (не-фото):**
`называй движение, медиум и эпоху: «арт-нуво иллюстрация», «рисограф-принт 1970-х», «цел-анимация 80-х»`

## 6. Рабочий процесс итераций

1. **Черновик** — базовая идея (субъект + среда).
2. **Генерация** — быстрый/дешёвый режим.
3. **Диагноз** — что точно, что мимо, чего не хватает.
4. **Правка** — одно слабое место за раз.
5. **Фиксация** — композиция удалась → локнуть сид, дальше только полировка.
6. Передавай результат в постобработку (ретушь, вёрстка) — промпт сразу закладывал «готовность к передаче».
