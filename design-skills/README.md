## Как агент это использует

Для любой дизайн-задачи (постер, лендинг, логотип, баннер, UI, иллюстрация, генерация картинки):

1. Сверяюсь с фундаментом (§02) — иерархия, контраст, сетка, цвет.
2. Применяю актуальные тренды 2026 (§01), если это уместно бренду.
3. Проверяю доступность по §03 (контраст, типографика, фокус) — обязательно.
4. Для генерации изображений пишу промпты по формулам из §04.
5. Ищу референсы и свежие идеи в источниках из §05 (умею читать страницы из интернета).
